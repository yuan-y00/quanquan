推荐文件结构

文件
先写什么
后写什么
pc_app/app.py
串口选择、Connect、Home、Stop、M114、手动 XYZ、动作按钮。
接入语音开关、视觉开关、动作状态显示。
pc_app/serial_link.py
打开串口、关闭串口、发送一行 G-code，默认结尾 \r。
读取固件返回文本，写入 UI 日志。
pc_app/gcode.py
生成 G28、G90、G1 X Y Z F、G4 S、M114、M119、M18。
统一格式化数值，避免 UI 直接拼字符串。
pc_app/motion_scripts.py
把 handshake、happy、shy、sleep 写成 G-code 序列。
从 poses.json 读取可调坐标点。
pc_app/poses.json
保存待机、伸手、摇上、摇下、开心、害羞、睡觉坐标。
由 UI 示教功能更新。
pc_app/voice.py
先从电脑麦克风录音，把英文语音转成文字。
再把听到的句子交给 intent.py。
pc_app/intent.py
先写固定英文口令匹配，比如听到 shake hand 就返回 handshake。
再增加更多可爱口令，比如 good boy、sleep、wake up。
pc_app/speech_out.py
先让电脑扬声器播放英文句子，比如 Okay!、I am here.。
再把不同动作绑定不同回应，让声音和动作一起发生。
pc_app/vision.py
先打开摄像头，显示画面。
再接入手部识别结果，判断左、中、右、远、近。
pc_app/hand_tracker.py
先用 MediaPipe 找手掌关键点。
再输出简单状态：没有手、手在中间、手靠近、手离开。
pc_app/config.py
串口号、波特率 115200、命令结尾 \r、默认速度。
摄像头编号、语音开关、调试参数。

写代码顺序

  1. 写 config.py，保存波特率 115200、命令结尾 \r、默认速度。
  2. 写 serial_link.py，打开串口，发送一行 G-code，读取返回文本。
  3. 写 gcode.py，统一生成 G28、G90、G1、G4、M114、M119、M18。
  4. 写 app.py，做 Connect、Home、Move XYZ、Status、Motors Off。
  5. 写 poses.json，先填占位坐标，后续示教替换。
  6. 写 motion_scripts.py，把动作变成 G-code 序列。
  7. 在 app.py 里加 Handshake、Happy、Shy、Sleep 按钮。

动作点 保存内容 用途

shake_down X Y Z F 握手下摇
happy_left / happy_right X Y Z F 开心摆动

sleep X Y Z F 睡觉

阶段二：电脑麦克风和扬声器版

固定英文口令

你说 quanquan 说 quanquan 做
Quanquan, wake up. I am here. wake_up
Shake hand. Okay, hand please. handshake_ready + handshake_shake
Again. Again! handshake_shake
Good boy. Hehe. happy_wiggle
Be shy. Oh no. shy_back
Go to sleep. Good night. sleep

写代码顺序

  1. 写 speech_out.py，先让电脑能说英文。
  2. 写 intent.py，把固定英文句子映射成动作名。
  3. 写 voice.py，用电脑麦克风识别英文。
  4. 修改 app.py，增加 Start Voice 和 Stop Voice。
  5. 把语音识别结果、英文回应、机械臂动作连起来。

阶段三：加摄像头版

摄像头互动

视觉状态 quanquan 的反应 动作名
没有看到手 安静待机，轻轻呼吸。 idle_breathe
手出现在画面中间 好奇地抬起来，准备互动。 curious
手慢慢靠近 伸出末端，准备握手。 handshake_ready
手突然很近 害羞后退一下。 shy_back
手离开 轻轻摆一下，然后回到待机。 happy_wiggle + idle_breathe

写代码顺序

  1. 写 vision.py，先打开 USB 摄像头并显示画面。
  2. 写 hand_tracker.py，用 MediaPipe 找到手掌关键点。
  3. 先只输出简单状态：没有手、左边、中间、右边、靠近。
  4. 修改 motion_scripts.py，增加 curious 和视觉触发动作。
  5. 修改 app.py，增加 Start Camera 和 Stop Camera，把视觉状态变成动作。
